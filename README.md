# ✨ 大模型 SDK
第三方大模型服务SDK，快速封装通用大模型能力，支持流式对话、上下文记忆、文生文、向量嵌入、参数微调，帮助业务快速接入AI大模型能力。
适用场景：智能问答、知识库问答、文案生成、代码辅助、对话机器人、AI智能改写

---
📌 一、项目介绍
本项目为 大模型官方SDK快速接入工具，对大模型官方接口进行二次封装，简化鉴权、请求组装、异常处理、流式解析、超时重试等逻辑，降低业务接入成本。
主要能力：
- ✅ 通用对话：普通问答、多轮上下文对话
- ✅ 流式输出：SSE 实时流式返回打字机效果
- ✅ 向量嵌入：文本 Embedding 向量生成
- ✅ 模型参数自定义：温度、最大生成长度、TopP、惩罚系数
- ✅ 异常重试、超时控制、熔断降级
- ✅ 日志埋点、请求耗时、Token 消耗统计

---
🛠 二、环境依赖
2.1 运行环境
- C++标准：C++11 及以上
- Maven：3.6+
- 网络：可访问大模型官方域名、放行443端口
2.2 模型支持列表
- 通用大模型：通义千问、文心一言、DeepSeek
- 轻量模型：通用轻量化对话模型
- 向量模型：text-embedding 向量化模型

💻 四、Git 提交规范参考

```c++
feat 增加新的业务功能

fix 修复业务问题 / BUG

perf 优化性能

style 更改代码风格，不影响运行结果

refactor 重构代码（既不新增功能也不修复 BUG）

revert 撤销 / 回滚之前的提交

test 测试相关，不涉及业务代码的更改

docs 文档和注释相关修改

chore 更新依赖 / 修改脚手架配置 / 构建流程等琐事（不影响业务逻辑）

workflow 工作流 / CI/CD 流程改进

ci 持续集成相关配置修改

types 类型定义文件更改（如 TypeScript 类型）

wip 开发中（临时提交，不建议合入主分支）

build 构建系统或外部依赖相关的修改

release 版本发布相关提交

hotfix 紧急线上 BUG 修复（需优先合入）

deps 依赖包版本更新或替换
```
